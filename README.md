# Student Service Portal

A web-based Student Service Portal developed using Spring Boot, Java, HTML, CSS, JavaScript, and MySQL.

## Features

- Student Login
- Student Registration
- Student Profile
- Attendance
- Marks / Results
- Timetable
- Assignments
- Notices / Announcements
- Leave Requests
- Certificates
- Fee Information
- Complaints / Helpdesk
- College Events
- Faculty Information

## How to Run

1. Install Java 17 or later.
2. Install MySQL.
3. Configure the database settings in:
   backend/src/main/resources/application.properties
4. Open the backend project in VS Code.
5. Run the Spring Boot application using Maven.
6. Open the browser and visit:

http://localhost:8080/
